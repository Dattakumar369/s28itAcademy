# Technology Images Folder

Add your technology logo images (PNG format) to this folder.

## Image Naming Convention

Name your PNG files according to the technology names:

- `java-development.png` - For Java Development
- `multi-cloud-devops.png` - For Multi Cloud with DevOps
- `automation-testing.png` - For Automation Testing
- `etl-testing.png` - For ETL Testing
- `workday.png` - For Workday
- `sap-grc.png` - For SAP GRC

## Image Specifications

- **Format:** PNG (with transparent background recommended)
- **Size:** Recommended 400x400px to 600x600px for best clarity and visibility
- **Minimum Size:** At least 300x300px to ensure good quality display
- **Aspect Ratio:** Square (1:1) works best, but rectangular logos are also fine
- **File Size:** Keep under 1MB for optimal performance (larger files are acceptable for quality)
- **Background:** Transparent background is recommended for best visual effect
- **Quality:** High resolution images (300 DPI or higher) will look crisp and clear on all devices
- **Resolution:** Use high-resolution images to avoid pixelation when displayed at larger sizes

## How It Works

1. Add your PNG images to this folder with the exact filenames listed above
2. The images will automatically display in the "Available Technologies" section
3. If an image is missing, the technology name will be displayed as a fallback

## Adding New Technologies

If you want to add more technologies:

1. Add the image file to this folder
2. Update `src/components/CareerRestartProgram.js` to add a new tech-item
3. Use the same naming pattern: `technology-name.png` (lowercase, hyphens for spaces)
